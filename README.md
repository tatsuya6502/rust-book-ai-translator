# rust-book-translator

Rust製のドキュメント翻訳ツールです。The Rust Programming Languageなどの英語で書かれたMarkdownドキュメントを、ローカルのLLM（Ollama）を使って日本語に翻訳します。

## 主な機能

- **スマートチャンキング**: 約800トークン単位でドキュメントを分割してLLMに与えることで、翻訳の品質を向上させます。分割の際にはコードブロックと段落の境界を考慮します
- **用語集による一貫性**: YAML形式の用語集を使って、技術用語の翻訳を統一します
- **チェックポイント機能**: 翻訳の進捗を保存し、中断後も再開できます
- **フォーマット保持**: コードブロックは翻訳せず、Markdownの書式を維持します
- **リトライ機能**: 失敗時に最大3回まで再試行します

## 必要な環境

- Rust 2024 Edition
- Ollamaサーバー（http://localhost:11434）

## 使い方

```
cargo run --release
```

以下については `src/main.rs` の定数で設定してください。

- 翻訳対象ファイル
- 出力ファイル
- 用語集ファイル
- 使用モデル（TranslateGemma 12Bなど）

将来はコマンドライン引数で指定できるようにする予定です。

## 開発

### 仕様

仕様はOpenSpecで管理しています。`openspec` フォルダ内のMarkdownファイルを参照してください。

### 実装作業

コーディングにはClaude Codeを使用しています。
ただし、予算の都合上、モデルはClaudeではなく、Z.ai GLMを使用しています。

### PRレビュー

PRの1次レビューにはCodeRabbitを使用しています。
その後、人間による最終レビューを行っています。
